Welcome to the Student Performance Predictor! This tool estimates students’ final exam scores based on study hours, attendance, and previous exam marks. Explore the interactive form below to see predicted performance in real time.

About This Project

The objective of this project is to predict student academic performance using key data points. Using statistical analysis and a machine learning model, it calculates estimated final marks.

Technologies used:

  • Frontend: HTML5, CSS3, JavaScript
  • Backend: Python (Flask)
  • Libraries: pandas, numpy, scikit-learn
